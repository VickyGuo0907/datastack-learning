# Welcome to Modern Data Stack Learning!

This documentation site is a collection of notes, concepts, and explorations related to the **Modern Data Stack (MDS)**. 
Whether you're new to the MDS or looking to deepen your understanding of its various components, you'll find helpful information here.

## What You'll Find Inside:

This site is organized into several key areas:

*   **Data Stack Concepts**: Fundamental ideas, comparisons (like ETL vs. ELT), and overviews of different architectural approaches within the data world.
*   **Data Workflow Tools**: Information on tools and practices for orchestrating and managing data pipelines and workflows.
*   **Data Governance**: Insights into metadata management and other governance aspects crucial for a robust data strategy.

Navigate through the sections using the menu on the left to explore these topics.
